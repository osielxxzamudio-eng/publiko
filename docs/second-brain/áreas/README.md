# Áreas — Áreas de Responsabilidad

Aquí se almacenan las notas de responsabilidades de **largo plazo sin fecha de fin definido** que requieren mantenimiento continuo.

## Cómo añadir un área

1. Crea un archivo Markdown con nombre descriptivo, por ejemplo:
   `documentacion-equipo.md` o `infraestructura.md`
2. Incluye: propósito, métricas de salud, revisiones periódicas y contactos/recursos clave.
3. Cuando el área deje de ser relevante, mueve el archivo a `archivos/`.
