# Archives — Elementos Archivados

Aquí se almacenan proyectos completados, áreas descontinuadas y recursos ya no activos, movidos desde `projects/`, `areas/` o `resources/`.

## Propósito

Mantener un registro histórico sin ensuciar las carpetas activas. Permite consultar información pasada sin distraer del trabajo actual.

## Cómo archivar

Mueve el archivo correspondiente desde su carpeta de origen aquí. Opcionalmente, añade una nota al principio del archivo indicando la fecha de archivo y el motivo.
