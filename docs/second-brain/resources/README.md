# Resources — Temas de Referencia

Aquí se almacenan notas de **interés y referencia sin obligación activa**: tutoriales, enlaces, artículos, fragmentos de código y aprendizajes sueltos.

## Cómo añadir un recurso

1. Crea un archivo Markdown con nombre descriptivo en inglés, por ejemplo:
   `git-comandos-basicos.md` o `notas-conferencia-2026.md`
2. Incluye: descripción, fuente/origen, etiquetas y por qué es útil.
3. Cuando el recurso deje de ser útil, muévelo a `archives/`.
