# Proyectos — Proyectos Activos

Aquí se almacenan las notas de iniciativas con **objetivo definido y fecha de fin**. Cada proyecto tiene un resultado concreto entregable.

## Cómo añadir un proyecto

1. Crea un archivo Markdown con nombre descriptivo, por ejemplo:
   `2026-10-27-configurar-ci-cd.md`
2. Incluye al menos: objetivo, estado, fecha de inicio, fecha límite prevista y próximos pasos.
3. Cuando el proyecto se complete, mueve el archivo a `archivos/`.
